# PorMyCodex - תוכנת מקריא ספרים חכם בעברית מבוסס AI 📖🖥️

תוכנת שולחן עבודה מקורית (Desktop App - PyQt6) למחשב, המיועדת להקראת ספרים, מסמכים וטקסטים עבריים באיכות דיבור טבעית ופונטיקה מדויקת.
כוללת מנוע בלשנות AI (מבוסס Gemini 3.8) לניקוד מלא ופתיחת ראשי תיבות, ומנוע קול רב-ערוצי (Edge-TTS נוירלי + SAPI5 מקומי).

---

## ✨ תכונות מרכזיות

* **תוכנה שולחנית עצמאית לחלוטין (Desktop EXE / PyQt6)**:
  * ללא תלות בדפדפן או בשרתים חיצוניים להשמעה.
  * ממשק עברי מודרני מותאם RTL בערכת נושא כהה (Dark Slate/Amber).
  * קיצורי מקלדת (רווח להפעלה/השהיה, חצים לניווט בין משפטים).

* **איכות קול נוירלית גבוהה (Dual Audio Engine)**:
  * **Edge-TTS Neural**: קולות עבריים באיכות אולפן טבעית (`he-IL-AvriNeural` גבר, `he-IL-HilaNeural` אישה) ללא עלות.
  * **Windows SAPI5**: מנוע הקול המקומי של Windows (עובד 100% Offline ללא רשת).

* **בלשן AI חכם (Gemini 3.8 Flash)**:
  * **ניקוד מלא**: מוסיף ניקוד מדויק לכל המילים כדי למנוע שיבושים במילים כמו סֵפֶר/סַפָּר.
  * **פתיחת קיצורים וראשי תיבות**: רמב"ם ➔ רַבֵּינוּ מֹשֶׁה בֶּן מַיְמוֹן, עכ"פ ➔ עַל כָּל פָּנִים, אחה"צ ➔ אַחַר הַצָּהֳרַיִם, ביהמ"ש ➔ בֵּית הַמִּשְׁפָּט ועוד.
  * **עוזר ספרותי מובנה**: ביאור מילים קשות ומושגים, סיכום פרק ושאלות הבנה.

* **תמיכה בקבצים וספרייה**:
  * פתיחת קבצי TXT, Markdown, PDF ו-Word (DOCX).
  * ספרי מופת מובנים (ספר משלי, רמב"ם הלכות דעות).
  * אפשרות הדבקת טקסט חופשי.

## 🚀 הפעלה ובנייה

### אפשרות 1: הרצה ישירה ב-Python
```bash
# התקנת תלויות
pip install -r requirements.txt

# הפעלת התוכנה
python main.py
```

### אפשרות 2: הידור לקובץ EXE עצמאי (Windows)
פשוט לחץ פעמיים על:
```bat
build_exe.bat
```
הסקריפט יתקין את כל החבילות הנדרשות וייצור קובץ `dist\PorMyCodex.exe` שניתן להריץ בכל מחשב Windows ללא צורך בהתקנת Python!

## 📂 מבנה הפרויקט

* `main.py` - נקודת הכניסה הראשית, הגדרות High DPI, כיווניות עברית (RTL).
* `main_window.py` - ממשק המשתמש השולחני המלא (PyQt6).
* `audio_engine.py` - מנוע השמעת האודיו וניהול התהליכונים (QThread).
* `ai_linguist.py` - חיבור ל-Gemini 3.8 לניקוד, פתיחת קיצורים וביאורים.
* `book_loader.py` - מנגנון טעינה ופירוק קבצים לפרקים ומשפטים.
* `style.py` - ערכת נושא מעוצבת ב-QSS.
* `PorMyCodex.spec` - הגדרות PyInstaller לבניית EXE.
* `build_exe.bat` - קובץ הפעלה לבנייה אוטומטית.
* `requirements.txt` - רשימת הספריות הנדרשות.
